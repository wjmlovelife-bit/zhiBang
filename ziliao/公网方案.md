## 二、为何不能直接公网访问？

| 原因 | 说明 |
|---|---|
| 无公网 IP | 运营商给的是**内网 IP（NAT 后）**，外网无法直接找到 |
| 防火墙 | 即便有公网 IP，公司/家庭路由器一般也会拦截入站 |
| 安全裸奔 | 即便能开，HTTP 明文传输，账号密码泄露 |

要公网访问，必须借助一种"反向连接"机制——让**你电脑主动连到公网服务器，建立加密隧道**，公网用户反向走这条隧道访问。

## 四、⭐ 推荐方案 A：Cloudflare Tunnel

### 4.1 原理图

```
  [外部用户]
      ↓ 浏览器打开 https://crm.xxx.trycloudflare.com
  [Cloudflare 公网 CDN]  ← Cloudflare 全球 200+ 节点，免费
      ↓ 加密隧道（你电脑主动建立）
  [cloudflared.exe]  ← 你电脑上常驻的小进程
      ↓ 转给本机 8080
  [8080 静态服务]
      ↓ 代理 /api 给 3001
  [NestJS 后端]
      ↓ 查 PG
  [PostgreSQL]
```

### 4.2 核心优势

- ✅ **零公网 IP 要求**（NAT 后也能用）
- ✅ **不需要开路由器端口**
- ✅ **不需要装证书**（自动 HTTPS）
- ✅ **完全免费**（免费额度：每天 10 万请求，5~50 人团队绰绰有余）
- ✅ **全球 CDN 加速**
- ✅ 命令一行就能跑起来

### 4.3 限制

- 你电脑关机，公网访问就不可达
- 默认试用域名（`*.trycloudflare.com`）重启会变 → 解决：配置模式 ② 固定域名

## 五、两种域名模式

### 模式 ① 零域名模式（试用 / 调试）⭐ 5 分钟体验

```powershell
cloudflared.exe tunnel --url http://localhost:8080
```

启动后输出会包含：

```
Your quick Tunnel has been created! Visit it at:
https://xxx-xxx-xxx.trycloudflare.com
```

把这个 URL 发到外网（关 WiFi 用 4G 的手机）就能访问 CRM 了。

**缺点**：每次重启命令域名会变。

### 模式 ② 长期固定域名模式（正式用）⭐⭐ 永久有效

需要自己的域名（如 `flyctd.com`），流程：

```
1. 买一个域名（一次性 ¥60/.com-年、¥30/.cn-年）
   ↓ 注册商推荐
   - Cloudflare Registrar（无加价）
   - NameSilo（便宜）
   - 阿里云/腾讯云（国内要实名）
2. 把域名的 NS（DNS 服务器）切到 Cloudflare
   ↓ 在域名注册商后台操作
3. 装 cloudflared，在 Cloudflare 后台授权登录
4. 创建隧道
   cloudflared tunnel create zhibang
5. 在 Cloudflare DNS 里绑定二级域名
   cloudflared tunnel route dns zhibang crm.yourcompany.com
6. 启动隧道守护进程
   cloudflared tunnel run zhibang
7. （推荐）注册成 Windows 服务
   cloudflared service install
8. 公网访问 https://crm.yourcompany.com → 自动到 8080
```

## 八、几个常见"坑"提前避坑

| 坑 | 影响 | 解决方案 |
|---|---|---|
| 电脑关机 → 域名不可用 | 公网访问打不开 | service install + BIOS AC Recovery（自动开机）|
| 网速看上传带宽 | 你公司上传 5Mbps 时 10 人并发可能慢 | 智邦 CRM 是 OLTP 单页面操作，影响小；多人同时大量上传才受影响 |
| 首次要登录 CF 授权 | 浏览器登录 Cloudflare 账号一次性 | 之后无感 |
| 试用域名每次重启都变 | 发出去的 URL 失效 | 升级到模式 ② |
| Cloudflare 政策禁用 BT/P2P | 智邦 CRM 不受影响 | — |

## 附录 A：常用命令速查

### 试

```powershell
# 一次性启动（前台运行，Ctrl+C 终止）
cloudflared.exe tunnel --url http://localhost:8080

# 后台启动
start "cloudflared-tunnel" cmd /k "cloudflared.exe tunnel --url http://localhost:8080 > D:\tmp\tunnel.log 2>&1"

# 查看状态
netstat -ano | findstr :8080

# 停止
taskkill /F /IM cloudflared.exe
```

### 生产

```powershell
# 登录授权（弹出浏览器）
cloudflared.exe tunnel login

# 创建命名隧道
cloudflared.exe tunnel create zhibang

# 绑定 DNS
cloudflared.exe tunnel route dns zhibang crm.yourcompany.com

# 启动
cloudflared.exe tunnel run zhibang

# 注册 Windows 服务（开机自启）
cloudflared.exe service install

# 启动/停止服务
sc start cloudflared
sc stop cloudflared

# 卸载服务
cloudflared.exe service uninstall
```

### 文件位置

| 工具 | 路径 |
|---|---|
| `cloudflared.exe` | `D:\zhibang\cloudflared.exe` |
| 配置文件 `config.yml` | `%USERPROFILE%\.cloudflared\config.yml` |
| 隧道凭据 `*.json` | `%USERPROFILE%\.cloudflared\*.json` |
| 日志 `tunnel.log` | `D:\tmp\tunnel.log` |
